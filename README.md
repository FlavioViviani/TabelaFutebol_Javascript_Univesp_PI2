# TabelaFutebol_Javascript_Univesp_PI2
Estatisticas do futebol semanal

Programa em javascript para registro de dados de um grupo de futebol
Criado para o Projeto Integrador II do curso de Tecnologia da Informação da faculdade UNIVESP

-----------------

O programa consiste em registrar os resultados das partidas de futebol 
Registrar os dados indivíduais de cada atleta e também fazer o comparativo entre eles, através de rankings e tabelas.
